## The six evidence-discipline commitments, and how each was honored

1. **Every new citation marks its evidence level explicitly** — done throughout §10.1–10.9's prose and in the table above; no citation in Chapter 10 is presented without an evidence-type label.
2. **No unverified market size, cost, sensitivity, or deployment-count figure appears** — every specific number in Chapter 10 (e.g., [60]'s prevalence-detection floor, [61]'s "58 of 147" ML-adoption figure, [62]'s turnaround time) is explicitly flagged "pending full-text verification" at first mention, consistent with the rest of this review, and none is asserted as a settled fact anywhere in the chapter or in Table 8.
3. **No preprint solely supports a key conclusion** — verified structurally: zero preprints appear anywhere in Chapter 10's reference list (contrast Chapter 9, which necessarily included two, one later withdrawn).
4. **No institutional project webpage is treated as proof of technical performance** — [64] (the one institutional/policy-adjacent source) is cited only for its standardization/proficiency-testing *argument*, never as evidence that any specific reference material or proficiency-testing program has been shown to work; §10.6's prose explicitly separates the argument from a performance claim.
5. **No detection-capability paper is treated as automatically establishing epidemiological inference capability** — this is §10.2's, §10.4's, and §10.5's explicit, repeated argument (a biosensor detecting a target is not the same as that detection informing a population-level inference), and §10.10's technology-readiness framework formalizes the distinction structurally rather than leaving it as a one-off caveat.
6. **Every "future"/"emerging" judgment distinguishes technically possible, field-demonstrated, operationally deployed, and decision-value-validated** — this is §10.10's entire content, and Table 8's "Readiness level (this review's assessment)" column applies the distinction to every technology surveyed in the chapter, finding none confidently above level 3–4 for routine public-health use — a finding stated directly in §10.10's closing paragraph, not left implicit.

## The one documented citogenesis catch

An initial search summary for [60] attributed the paper to **"Moore et al."** On inspection, this was identified as a citogenesis artifact: the **"Moore swab"** is a historically named passive-sampling *method* (unrelated to this specific 2021 paper's authorship), and the search tool's synthesis had conflated the method's namesake with the paper's actual author list. A dedicated re-search confirmed the correct, independently-verifiable first author as **Christelle Schang**, with a full 23-author list. This is recorded here — and in `WBE_Review_References.md`, the Citation Verification Table, and Chapter 10's own §10.0 status note — as a positive instance of this review's citation-verification discipline catching an error *before* it entered the main text, consistent with the same discipline that has previously caught and corrected author-order errors (Ahmed et al. [18], Zafeiriadou et al. [22]) and a misattributed lead author (McMahan et al. [42], previously mis-cited as "Nourbakhsh et al." in an earlier project round).
