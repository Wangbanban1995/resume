**What Table 7 is, stated once here as the authoritative framing.** Table 7 ("Surveillance Objective × Decision Requirement × Primary Uncertainty Sensitivity × Representative Citation") is **proposed by this review based on the conceptual synthesis of available guidance and methodological literature.** It is not a published, validated, or institutionally endorsed standard, and no cell in it should be read as an externally-verified empirical fact unless this audit specifically says so. This file exists because a table's compact, authoritative-looking format can misrepresent a cell's actual evidentiary basis more easily than prose does — every cell is therefore checked below against six questions: (1) is this cell original synthesis or an external fact; (2) does it need a citation at all; (3) does the citation actually support the specific claim in the cell; (4) does the cell depend on a single country/city/disease system without saying so; (5) is a guidance document being presented as empirical validation evidence; (6) does the cell contain an unverified number, threshold, or performance judgment.

## Cross-row findings

1. **Question (1) — original vs. external:** every "what decision-ready requires," "primary uncertainty sensitivity," and "fusion role" cell in all three rows is this review's own original synthesis, correctly requiring no citation. Only the "representative citation" column contains external facts, and this is by design — the table's caption now states this explicitly ("Proposed by this review... the 'representative citation' column names a real study illustrating the row, not a source that has validated the row's general claim across settings").
2. **Question (4) — single-system dependency:** present in every row ([8]: Belgium; [55]: single study, specific setting not independently confirmed this session; [57]: U.S./SARS-CoV-2; [44]: Calgary; [46]: chemical target, not pathogen). Every citation instance in the table now carries an explicit single-setting disclosure parenthetical, applied consistently as of this audit round.
3. **Question (5) — guidance mischaracterized as evidence:** does not occur anywhere in Table 7. No institutional/guidance source (WHO, NASEM, ECDC) appears in any "representative citation" cell — all five citations in the table are primary empirical studies, correctly distinguished from the institutional-guidance sources cited elsewhere in §9.8's prose.
4. **Question (6) — unverified numbers in the table itself:** none. Every specific performance figure (e.g., [57]'s sensitivity/PPV) lives in the main prose, where it is hedged, not duplicated into the table cell without its hedge.

## Overall verdict

Table 7 survives this audit as a **correctly-labeled original framework** rather than a disguised empirical claim. This audit's one substantive finding — an asymmetric disclosure of single-setting dependency between [55] and its row-mates ([57], [8], [44], [46]) — has been fixed in the main text as part of this same round, not merely logged for later. No cell was found to misattribute a guidance document as validation evidence, and no cell was found to assert an unverified number without the hedge that number already carries in the main text. The table's caption disclaimer ("Proposed by this review...") is judged, on this audit, to be necessary and sufficient to prevent a reader from mistaking it for a validated external standard, provided it is not stripped out in any future extraction of this table into a standalone deliverable (as Chapters 5–8's tables were — see the "Note on companion files" list, which does not currently include a standalone Table 7 extract; if one is created in a future round, this disclaimer must travel with it).
